About SecurePass

A simple cybersecurity awareness project focused on password security.

What is SecurePass?

SecurePass is a web-based cybersecurity awareness application designed to help users understand the importance of strong and secure passwords.

The application allows users to check password strength, generate strong passwords, and learn basic cybersecurity practices.

Main Features

  • 🔐 Password Strength Checker
  • 🔑 Password Generator
  • 🛡️ Cybersecurity Awareness Tips
  • 🔒 Privacy-focused local password checking

HTML – Website structure

CSS – Website styling

JavaScript – Interactive functionality
